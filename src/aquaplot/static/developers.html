Developers

Try a real Claude reading from this browser. Save a Claude API key here, and the checks you make in this browser send your photos to Claude on that key.

Claude API key

How the key is used

  • It stays in this browser until you press "Forget the key". The server does not keep it.
  • It is sent only with checks you make from this browser, and used for that check alone. It is never saved with the check, and never appears in a result, report or export.
  • Each photo you check is one Claude request, billed to the key's account. The sample photos replay a recording and cost nothing, and a review never asks the model again.
  • Your checks don't use up this server's live readings, and nobody else's checks use your key.

Before you paste one

  • Make a separate key for AquaPlot in the Anthropic Console, and set a spending limit on it.
  • Anyone using this browser can make checks on the key. Don't save it on a shared computer.
  • To give every visitor live readings instead, set ANTHROPIC_API_KEY where the server runs (see the README). The live-reading limits then protect that key.

API

The API reference lists every endpoint. A check sends the key in the X-AquaPlot-Claude-Key header of POST /api/assess.
